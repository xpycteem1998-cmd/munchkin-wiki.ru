# Проверки сайта

## Состояние на 10 сентября 2026

Сайт содержит 4 290 HTML-страниц, 4 049 карточек, 73 набора и 59 материалов
FAQ в восьми тематических папках. В поиске 4 182 записи. Исторические адреса
разъяснений перенаправляют в FAQ. В sitemap включены 4 228 индексируемых страниц.

Эпический Манчкин представлен самостоятельной HTML-статьёй: начало партии,
эпический статус, две Двери, победа, спорные ситуации, 14 рас и классов
фэнтезийной серии и три усилителя из восьмого дополнения. Для чтения статьи
PDF не нужен. Исторический домашний режим явно отделён от турнирных правил.

## Автоматическая проверка

```bash
python3 scripts/build_site.py
python3 scripts/validate_site.py
python3 -m unittest discover -s tests -v
python3 scripts/test_browser.py
```

Локальная проверка на Python 3.14.4 и Firefox завершилась успешно:

- Валидатор: 68 444 внутренних ссылки на страницы/ресурсы, дополнительно
  проверены внутренние якоря; ошибок нет.
- 914 встроенных ссылок и 158 блоков вопрос–ответ.
- 12 тестов: сохранение смысла зачёркнутого текста, точные URL пруфов,
  вложенные ссылки из некорректного оригинала, альтернативные названия,
  целостность каталога, метаданные, независимые контрольные примеры.
- Браузер: релевантность поиска, фильтры, адресная строка, выдача следующих
  результатов, отмена устаревшего запроса, повтор после ошибки загрузки,
  открытие FAQ по якорю и 32 проверки адаптивной вёрстки (320/390/820/1200 px).
- У всех карточек сохранены страницы и ссылки в статическом постраничном каталоге.

GitHub Actions настроен на Python 3.12/3.13 и браузерную проверку на Ubuntu 24.04.
Удалённый запуск CI не является частью локальной проверки; workflow начнёт
работать после отправки изменений в репозиторий.

## Размер загрузки

Главная страница каталога карточек занимает 19 650 байт вместо прежних
963 890: за один раз показываются 100 карточек, а не весь архив.
Поиск по-прежнему охватывает весь каталог. Более полный индекс занимает
1 612 334 байта; оценка при gzip — 299 142 байта. Это измерение файлов,
не замер загрузки с публичного хостинга. Настройка сжатия приведена в
`deploy/README.md`, но на сервер автоматически не применяется.

## Внешние источники: ограничения

Отчёт `exports/external_link_status.json` содержит 789 адресов:

- 22 доступны автоматическому запросу;
- 581 вернул отказ в доступе;
- 175 не проверялись индивидуально после повторных отказов того же хоста;
- 2 вернули другую HTTP-ошибку;
- 9 не удалось проверить из-за ошибки соединения.

Форум Steve Jackson Games на проверенных HTTP- и HTTPS-адресах возвращает
Cloudflare challenge. Это не доказательство, что обсуждения исчезли.
Ни один из этих отказов не переименован в «битую ссылку». Исходные адреса
сохранены, ограничения автоматической проверки показаны отдельно, предложен
поиск архивной копии без обещания её наличия. Проверка HTTP не подтверждает
правильность или актуальность игрового ответа.

Отдельный экспорт разметки привязан к 3 852 точным архивным версиям и хешам
текстов. Обычная сборка не требует raw-файлов или SQLite. Они не изменены и
не включены в публичный каталог. См. README для воспроизводимого обновления.

## Публикация

Настроены canonical, sitemap, favicon, версии CSS/JS/индекса и обратная связь.
Шаблоны Nginx/Apache предусматривают HTTPS, сжатие, кеширование с перепроверкой
и правильный 404. Push, изменение хостинга и выдача TLS-сертификата отдельно
не выполнялись.
