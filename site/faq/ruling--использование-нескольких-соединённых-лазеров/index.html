Иметь в составе соединённого оружия несколько -азеров-Агрегатов можно. [пруф]
В случае, если несколько -азеров соединены в одно оружие, "Чит" нельзя использовать на это оружие целиком, а можно только на один из -азеров (например, если два из -азеров являются Агрегатами, а ты можешь использовать только один). [пруф]
Нельзя подвергнуть всё оружие целиком Аннигиляции или Антиматерии... только одну карту! Источник: правила игры (без ссылки в оригинале)
Нельзя украсть всё оружие сразу, а только по одному -азеру. [пруф] Потому что несколько лазеров считаются одним оружием, но не одной шмоткой. [пруф]
